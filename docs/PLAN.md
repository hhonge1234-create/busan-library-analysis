## 기술
- 덱 엔진: 단일 `index.html` + 자체 내비게이션(←/→, 스페이스, 클릭, 진행 바, 슬라이드 번호, `#n` 해시)
- 슬라이드 진입 시 anime.js(3.2.2) 타임라인 재생 / manim 영상은 진입 시 처음부터 재생
- 차트 데이터: `analysis/make_deck_assets.py`가 CSV에서 집계 → `docs/assets/data.json`, matplotlib SVG
- manim 영상: `analysis/manim_scenes.py` → `docs/assets/*.mp4`
- 원본 CSV(100MB)는 레포에 올리지 않음

## 검증 루프
1. headless Chrome으로 전 슬라이드를 애니메이션 종료 후 스크린샷
2. 자동 점검: 콘솔 오류, 404 리소스, 슬라이드 밖으로 넘친 요소, 영상 로드
3. 스크린샷을 직접 보며 겹침·가독성 확인 → 수정 → 재검증 (문제 0건까지 반복)
4. 배포 후 Pages URL에서 한 번 더 확인
